# Stretching App (SwiftUI)

Questa repository contiene un esempio minimale di applicazione di stretching scritta in SwiftUI. Il codice fornisce una base da cui partire per creare un'app con cinque sezioni: Home, Allenamento, Attività, Profilo e Impostazioni.

## Come iniziare

1. Apri Xcode e crea un nuovo progetto **App iOS** scegliendo l'opzione *SwiftUI*.
2. Copia i file presenti nella cartella `StretchingApp` nel progetto Xcode appena creato.
3. Aggiungi eventuali video o risorse (ad esempio `background.mp4`) al bundle dell'app.
4. Esegui l'app su un simulatore o dispositivo reale.

L'app, al primo avvio, richiederà il consenso a inviare notifiche e a usare la posizione. Dalla schermata Home è possibile effettuare il login (placeholder) e accedere alle altre sezioni tramite la barra in basso.

Per personalizzare grafica e funzionalità puoi modificare o estendere le viste SwiftUI presenti nei file.
